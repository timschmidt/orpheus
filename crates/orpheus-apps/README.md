# orpheus-apps

Screens and app logic over service traits (05 §5.1, §6, §7.11; WP UI-2).
`#![no_std]`, no allocator, `#![forbid(unsafe_code)]`, no hardware. It runs on
the player through the firmware's implementation of [`Services`] and in the
simulator (`sim/src/apps.rs`) through scriptable fakes.

## Contents

| Module | Content |
|---|---|
| `services` | The service traits (below), `status()`, `mini_player()`, `palette()` helpers |
| `settings` | Every Settings group and item of 05 §7.11 with store key, kind, range, default; `encode`/`decode`; `SettingsCache` |
| `strings` | `Str` ids, built-in English `EN`, `Lang` (English + optional `YLN1` pack), `tr!(lang, Id)` |
| `screens` | `AppScreen` (the `ScreenSet`), Home, Settings root/groups/choices/info, slider, time/date picker, Home-screen editor, power menu, quick panel, USB connect dialog, lock screen, charging, boot, notices, goodbye |
| `browse` | `DirId`, `FileRef` (the orpheus-fs locator), `EntryKind` by extension, the one collation of 04 §6.1 (`natural_cmp`, case folding, numbers by value), `letter_of` for letter jump. Shared with the firmware's directory index |
| `icons` | 24 × 24 2-bit icons for the eleven apps and notices, generated by `icongen/icons.py` (original drawings) |

## Service traits (all synchronous, answered from cached state)

```rust
pub trait SettingsService {
    fn setting(&self, id: SettingId) -> i16;          // validated, default if unset
    fn set_setting(&mut self, id: SettingId, value: i16); // apply now; store write debounced by the firmware;
                                                      // then send ServiceEvent::SettingChanged(id.0)
    fn factory_reset(&mut self);
}
pub trait PowerService {
    fn battery(&self) -> BatteryInfo;                 // { percent: u8, millivolts: u16, charge: orpheus_power::charger::ChargeState }
    fn sleep_timer_left(&self) -> Option<u16>;        // minutes
    fn power(&mut self, req: PowerRequest);           // PowerOff, Restart, StartOriginal, Recovery, LockKeys,
                                                      // LockNoticeDone, StartFromCharging
}
pub trait ClockService {
    fn now(&self) -> DateTime;                        // local time { year, month, day, hour, minute, second, weekday }
    fn set_now(&mut self, t: DateTime);
    fn clock_valid(&self) -> bool;
}
pub trait StorageService {
    fn card(&self) -> CardState;                      // Absent, Mounting, Ready, Unreadable, UsbOwned
    fn card_info(&self) -> Option<CardInfo>;          // { capacity_mib, free_mib, fs: FsKind }
    fn storage(&mut self, req: StorageRequest);       // RebuildLibrary, ClearCaches, CheckCard, Format
}
pub trait PlaybackService {
    fn playing(&self) -> Option<Playing<'_>>;         // { source: Source, title, artist, progress 0..=1000 }
    fn volume_step(&mut self, delta: i8) -> (u8, u8); // (level, max)
}
pub trait UsbService {
    fn usb(&self) -> UsbState;                        // Detached, Charger, Host
    fn select_usb(&mut self, mode: UsbMode);          // ChargeOnly, FileTransfer, DiskImage, Keyboard, Audio
}
pub trait BluetoothService {
    fn bt(&self) -> BtState;                          // orpheus_ui::event::BtState
    fn bt_device(&self) -> &str;
}
pub trait SystemService {
    fn lang(&self) -> Lang;                           // switch packs when SettingChanged(LANGUAGE)
    fn language_count(&self) -> usize;                // index 0 = English
    fn language(&self, i: usize) -> Lang;
    fn version(&self) -> &str;
    fn build_id(&self) -> &str;
    fn serial(&self) -> &str;
    fn hardware(&self) -> &str;
    fn app_available(&self, app: App) -> bool;
    fn dual_boot(&self) -> bool;
    fn usb_audio_built(&self) -> bool;
    fn keys_locked(&self) -> bool;
}
pub trait Services: orpheus_ui::System + BrowseService + TextService + PlayerService
    + SettingsService + PowerService + ClockService + StorageService + PlaybackService
    + UsbService + BluetoothService + SystemService {}   // blanket impl
```

Files and Music (UI-3, UI-4). Rows are windowed: `entry`/`queue_entry`
answer only for rows the service holds; `want`/`want_queue`/`want_text`
move the window and are answered with `Event::Data { tag: data::BROWSE |
QUEUE | TEXT | LYRICS, .. }`. Nothing ever holds a whole directory.

```rust
pub struct DirId(pub u32);                       // a directory's first cluster; DirId::ROOT = 0
pub struct FileRef { pub dir: u32, pub index: u32 }   // orpheus-fs Locator (parent cluster, entry index)
pub enum EntryKind { Dir, Audio, Playlist, Image, Text, DiskImage, Firmware, OtpImport, Other }
pub enum SortBy { Name, Date, Size }
pub struct BrowseFilter { pub sort: SortBy, pub hidden: bool, pub audio_only: bool }
pub struct Entry<'a> { pub name: &'a str, pub kind: EntryKind, pub size: u64, pub modified: DateTime,
                       pub file: FileRef, pub child: DirId }
pub struct Listing { pub dir: DirId, pub count: u32, pub sorted: bool, pub complete: bool }
pub enum FileOp { Delete(FileRef) }
pub trait BrowseService {
    fn browse(&mut self, dir: DirId, filter: BrowseFilter) -> Listing;   // dirs first, then per SortBy,
                                                                        // ties natural_cmp; filter applied
    fn listing(&self) -> Listing;
    fn entry(&self, i: u32) -> Option<Entry<'_>>;      // None: not in the window → placeholder row
    fn want(&mut self, first: u32, count: u32);        // → Event::Data(BROWSE)
    fn position(&self, f: FileRef) -> Option<u32>;     // keeps focus across the re-sort
    fn letter(&self, i: u32) -> Option<char>;          // browse::letter_of(name)
    fn seek_letter(&self, from: u32, forward: bool) -> Option<(u32, char)>;   // from the index
    fn dir_name(&self, dir: DirId) -> &str;
    fn file_op(&mut self, op: FileOp) -> bool;
}
pub trait TextService {
    fn text_open(&mut self, f: FileRef) -> Option<u32>;   // size
    fn text_window(&self) -> (u32, &[u8]);                // (file offset, bytes); ≥ 1 KiB recommended
    fn want_text(&mut self, offset: u32);                 // → Event::Data(TEXT)
    fn text_position(&self, f: FileRef) -> u32;           // remembered reading position
    fn set_text_position(&mut self, f: FileRef, offset: u32);
}
pub struct PlayerState { pub source: Source, pub position_ms: u32, pub duration_ms: u32, pub queue_pos: u32,
    pub queue_len: u32, pub a_ms: Option<u32>, pub b_ms: Option<u32>, pub buffer_pct: u8, pub cpu_pct: u8 }
pub struct TrackInfo<'a> { pub title: &'a str, pub artist: &'a str, pub album: &'a str, pub file: FileRef,
    pub path: &'a str, pub size: u64, pub codec: &'a str, pub sample_rate: u32, pub bits: u8, pub channels: u8,
    pub bitrate_kbps: u16, pub gain_cdb: Option<i32> }
pub struct QueueEntry<'a> { pub title: &'a str, pub artist: &'a str, pub duration_ms: u32 }
pub struct LyricLine<'a> { pub time_ms: Option<u32>, pub text: &'a str }
pub struct Bookmark<'a> { pub title: &'a str, pub position_ms: u32 }
pub struct Levels { pub peak: [u8; 2], pub hold: [u8; 2], pub bands: [u8; 16] }
pub enum ArtSize { Small /* 52×52 */, Full /* 128×128 */ }     // RGB565, decoded and scaled
pub enum LibraryState { Missing, Building { files: u32 }, Ready }
pub enum PlayerCmd { PlayPause, Stop, Next, Prev, SeekTo(u32), SeekBy(i32), Jump(u32), Remove(u32),
    MoveUp(u32), MoveDown(u32), PlayDir { dir: DirId, start: Option<FileRef>, shuffle: bool }, ShuffleAll,
    PlayNext(FileRef), AddToQueue(FileRef), SetA, SetB, ClearAb, Bookmark, Favourite, PlayBookmark(u32), Resume }
pub trait PlayerService {
    fn player(&self) -> PlayerState;                 // source Idle when nothing is queued
    fn track(&self) -> Option<TrackInfo<'_>>;
    fn queue_entry(&self, i: u32) -> Option<QueueEntry<'_>>;
    fn want_queue(&mut self, first: u32, count: u32); // → Event::Data(QUEUE)
    fn art(&self, size: ArtSize) -> Option<&[u16]>;
    fn lyrics_count(&self) -> u32;
    fn lyric(&self, i: u32) -> Option<LyricLine<'_>>;
    fn levels(&self) -> Levels;
    fn resume_title(&self) -> Option<&str>;
    fn bookmark_count(&self) -> u32;
    fn bookmark(&self, i: u32) -> Option<Bookmark<'_>>;
    fn library(&self) -> LibraryState;
    fn command(&mut self, c: PlayerCmd);
}
```

The UI decides the transport rules: Prev restarts the track after 3 s,
Prev/Next held seek by 2 → 5 → 10 → 30 s per repeat, OK held = `Stop`.
Shuffle, repeat, speed, sleep timer, output and EQ are settings
(`settings::id`), which the player follows; EQ band gains of the built-in
presets are `settings::EQ_GAINS`, the two custom curves are settings
`0x0D10..=0x0D19`, and `settings::eq_gains()` resolves any preset.

`orpheus_ui::System` is implemented with the helpers:
`fn status(&self) -> Status { orpheus_apps::services::status(self) }`,
`fn mini_player(&self) -> Option<MiniPlayer<'_>> { services::mini_player(self) }`,
`fn volume_step(..)` → `PlaybackService::volume_step`. Each frame the
firmware draws with `services::palette(&svc)`.

Events the screens react to (`Event::Service`): `Battery { percent, charging }`
(toast at 15 % and 10 %, notice at 5 %; send it when the percentage
changes), `Usb { host: true }` (connect dialog or the remembered mode),
`CardRemoved`/`CardInserted`, `SettingChanged(key)` (theme, accent and
language redraw everything), `Minute`, `Bluetooth(..)`, `Playback(..)`.

Starting: `Shell::<AppScreen, Fw>::new(&mut fw, now)` for Home, or
`Shell::with_root(&mut fw, screens::BOOT | screens::CHARGING, Arg(0), now)`.
The shell pushes `LOCK` on a locked key, `POWER_MENU` on Power held 1.5 s,
`QUICK_PANEL` on Menu held. Power tap is returned as
`Requests::screen_off`; while locked or off the firmware treats it as
wake-and-unlock.

## Settings model

67 items in 12 groups plus 13 app settings (Files sort and hidden, Now Playing
view, two custom EQ curves); 64 store a value. Every value is an `i16` stored as
2 bytes little-endian under its key (`0x0101..=0x0CFF`, group in the high
byte; ids are never reused). `decode` validates against the item (choice
index, range and step, toggle 0/1, bit mask) and falls back to the default.
`SettingsCache` (112 B) is the RAM copy: `load(key, bytes)` at boot,
`get`/`set` for the UI, `take_dirty()` yields `(key, [u8; 2])` to write
with `orpheus_settings::Store::set`. Keys used outside Settings are in
`settings::id`.

## Strings

`tr!(lang, AppMusic)` returns `&'static str`. English is built in; a pack
(`YLN1`: magic, count, code, name, (offset, len) table, UTF-8 data) loaded
into a `'static` arena translates by id and falls back to English per
string. The simulator builds Russian and Japanese test packs
(`sim/src/packs.rs`; not reviewed translations — WP UI-7 owns real packs).

## RAM (thumbv7em-none-eabihf)

| Item | Bytes |
|---|---:|
| `AppScreen` (largest variant: list screen, 13 prepared rows) | 648 |
| `Shell<AppScreen, _>` total (stack of 8 resume records, overlays, top screen) | ≈ 2 044 |
| `SettingsCache` (64 values + dirty mask) | 144 |
| `FilesScreen` / `TextScreen` / `NowPlayingScreen` / `EqualiserScreen` | 80 / 140 / 112 / 20 |
| `HomeScreen` / `PickerScreen` | 24 / 32 |

Transient stack: the Details view builds its rows (576 B) while drawing or
handling a key; the text viewer lays out one line in a 192-byte buffer.
The browse, queue and text windows are the services' (firmware) RAM.

Icons: 15 × 144 B rodata.

## Files and Music screens (UI-3, UI-4)

* **Files** (`FILES`, arg `DirId`): one screen per folder on the navigation
  stack (Back goes up, focus restored from the resume record). Rows: type
  icon, name, size of the focused file. First visit of a large folder shows
  on-disk order; when the service reports `sorted`, the focused file stays
  focused. Held Up/Down accelerates (1 → 5 → 20 rows per repeat); held
  Prev/Next jumps by letter through `seek_letter`. OK: folder → open, audio
  → `PlayDir` from that file + Now Playing, text → viewer, other types →
  a notice naming the app that will open them. Menu: Play folder, Shuffle
  folder, Play next, Add to queue, Properties, Delete…, Sort (name / date /
  size), Show hidden, Card info.
* **Text viewer** (`TEXT_VIEW`, arg row): word wrap (spaces, CJK with
  line-start rules), UTF-8 or Latin-1, Prev/Next page, Up/Down line, a
  position bar, position remembered per file.
* **Music** (`MUSIC`): Now Playing (when queued), Resume «title», Shuffle
  all, Building library…, Artists/Albums/Songs/Genres/Playlists/Recently
  added (dim until the library index exists), Folders (`MUSIC_FOLDERS`:
  the browser with audio and playlists only), Bookmarks.
* **Now Playing** (`NOW_PLAYING`): Standard (art, title in bold — regular
  weight when a word would otherwise break —, artist, album, format,
  queue position, progress with A–B marks, times), Big art (full screen,
  overlay for 3 s after a key), Lyrics (synchronised: current line
  highlighted), Up next (OK jumps; Menu removes/moves), Details (codec,
  bitrate, rate/bits, channels, ReplayGain, file, size, CPU, buffer), Levels
  (stereo peaks with hold, 16-band spectrum, ≤ 15 fps). Up/Down cycle views
  (remembered in `NP_VIEW`); in the two list views Up/Down move in the list
  and change the view past either end. Menu: Shuffle, Repeat ›, Add to
  Favourites, Bookmark here, A–B repeat ›, Speed, Equaliser…, Sleep timer…,
  Go to folder, Delete file….
* **Equaliser** (`EQUALISER`): preset name, five bands with values and
  frequencies, automatic pre-amp; Prev/Next band, Up/Down gain (a built-in
  preset is copied into Custom 1 first), OK opens the preset list.
