# yoton-apps

Screens and app logic over service traits (05 §5.1, §6, §7.11; WP UI-2).
`#![no_std]`, no allocator, `#![forbid(unsafe_code)]`, no hardware. It runs on
the player through the firmware's implementation of [`Services`] and in the
simulator (`sim/src/apps.rs`) through scriptable fakes.

## Contents

| Module | Content |
|---|---|
| `services` | The service traits (below), `status()`, `mini_player()`, `palette()` helpers |
| `settings` | Every Settings group and item of 05 §7.11 with store key, kind, range, default; `encode`/`decode`; `SettingsCache` |
| `strings` | `Str` ids, built-in English `EN`, `Lang` (English + optional `YLN1` pack), `tr!(lang, Id)` |
| `screens` | `AppScreen` (the `ScreenSet`), Home, Settings root/groups/choices/info, slider, time/date picker, Home-screen editor, power menu, quick panel, USB connect dialog, lock screen, charging, boot, notices, goodbye |
| `icons` | 24 × 24 2-bit icons for the eleven apps and notices, generated by `icongen/icons.py` (original drawings) |

## Service traits (all synchronous, answered from cached state)

```rust
pub trait SettingsService {
    fn setting(&self, id: SettingId) -> i16;          // validated, default if unset
    fn set_setting(&mut self, id: SettingId, value: i16); // apply now; store write debounced by the firmware;
                                                      // then send ServiceEvent::SettingChanged(id.0)
    fn factory_reset(&mut self);
}
pub trait PowerService {
    fn battery(&self) -> BatteryInfo;                 // { percent: u8, millivolts: u16, charge: yoton_power::charger::ChargeState }
    fn sleep_timer_left(&self) -> Option<u16>;        // minutes
    fn power(&mut self, req: PowerRequest);           // PowerOff, Restart, StartOriginal, Recovery, LockKeys,
                                                      // LockNoticeDone, StartFromCharging
}
pub trait ClockService {
    fn now(&self) -> DateTime;                        // local time { year, month, day, hour, minute, second, weekday }
    fn set_now(&mut self, t: DateTime);
    fn clock_valid(&self) -> bool;
}
pub trait StorageService {
    fn card(&self) -> CardState;                      // Absent, Mounting, Ready, Unreadable, UsbOwned
    fn card_info(&self) -> Option<CardInfo>;          // { capacity_mib, free_mib, fs: FsKind }
    fn storage(&mut self, req: StorageRequest);       // RebuildLibrary, ClearCaches, CheckCard, Format
}
pub trait PlaybackService {
    fn playing(&self) -> Option<Playing<'_>>;         // { source: Source, title, artist, progress 0..=1000 }
    fn volume_step(&mut self, delta: i8) -> (u8, u8); // (level, max)
}
pub trait UsbService {
    fn usb(&self) -> UsbState;                        // Detached, Charger, Host
    fn select_usb(&mut self, mode: UsbMode);          // ChargeOnly, FileTransfer, DiskImage, Keyboard, Audio
}
pub trait BluetoothService {
    fn bt(&self) -> BtState;                          // yoton_ui::event::BtState
    fn bt_device(&self) -> &str;
}
pub trait SystemService {
    fn lang(&self) -> Lang;                           // switch packs when SettingChanged(LANGUAGE)
    fn language_count(&self) -> usize;                // index 0 = English
    fn language(&self, i: usize) -> Lang;
    fn version(&self) -> &str;
    fn build_id(&self) -> &str;
    fn serial(&self) -> &str;
    fn hardware(&self) -> &str;
    fn app_available(&self, app: App) -> bool;
    fn dual_boot(&self) -> bool;
    fn usb_audio_built(&self) -> bool;
    fn keys_locked(&self) -> bool;
}
pub trait Services: yoton_ui::System + SettingsService + PowerService + ClockService
    + StorageService + PlaybackService + UsbService + BluetoothService + SystemService {}   // blanket impl
```

`yoton_ui::System` is implemented with the helpers:
`fn status(&self) -> Status { yoton_apps::services::status(self) }`,
`fn mini_player(&self) -> Option<MiniPlayer<'_>> { services::mini_player(self) }`,
`fn volume_step(..)` → `PlaybackService::volume_step`. Each frame the
firmware draws with `services::palette(&svc)`.

Events the screens react to (`Event::Service`): `Battery { percent, charging }`
(toast at 15 % and 10 %, notice at 5 %; send it when the percentage
changes), `Usb { host: true }` (connect dialog or the remembered mode),
`CardRemoved`/`CardInserted`, `SettingChanged(key)` (theme, accent and
language redraw everything), `Minute`, `Bluetooth(..)`, `Playback(..)`.

Starting: `Shell::<AppScreen, Fw>::new(&mut fw, now)` for Home, or
`Shell::with_root(&mut fw, screens::BOOT | screens::CHARGING, Arg(0), now)`.
The shell pushes `LOCK` on a locked key, `POWER_MENU` on Power held 1.5 s,
`QUICK_PANEL` on Menu held. Power tap is returned as
`Requests::screen_off`; while locked or off the firmware treats it as
wake-and-unlock.

## Settings model

67 items in 12 groups; 51 store a value. Every value is an `i16` stored as
2 bytes little-endian under its key (`0x0101..=0x0CFF`, group in the high
byte; ids are never reused). `decode` validates against the item (choice
index, range and step, toggle 0/1, bit mask) and falls back to the default.
`SettingsCache` (112 B) is the RAM copy: `load(key, bytes)` at boot,
`get`/`set` for the UI, `take_dirty()` yields `(key, [u8; 2])` to write
with `yoton_settings::Store::set`. Keys used outside Settings are in
`settings::id`.

## Strings

`tr!(lang, AppMusic)` returns `&'static str`. English is built in; a pack
(`YLN1`: magic, count, code, name, (offset, len) table, UTF-8 data) loaded
into a `'static` arena translates by id and falls back to English per
string. The simulator builds Russian and Japanese test packs
(`sim/src/packs.rs`; not reviewed translations — WP UI-7 owns real packs).

## RAM (thumbv7em-none-eabihf)

| Item | Bytes |
|---|---:|
| `AppScreen` (largest variant: list screen, 13 prepared rows) | 640 |
| `Shell<AppScreen, _>` total (stack of 8 resume records, overlays, top screen) | ≈ 2 036 |
| `SettingsCache` | 112 |
| `HomeScreen` / `PickerScreen` | 24 / 32 |

Icons: 15 × 144 B rodata.
